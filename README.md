# anugrah55.github.io

My portfolio: a PSP-3000 floating in space, built in Three.js. Scroll to catch it, then browse projects, open-source work and RL environments on its screen.

Live at **https://anugrah55.github.io/** · plain-text version at **https://anugrah55.github.io/#text**

Single file (`index.html`), no build step. Three.js loads from a CDN; every texture is drawn to a canvas and every sound is synthesised in Web Audio.
